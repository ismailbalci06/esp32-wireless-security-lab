# GitHub publishing checklist

- [ ] Replace the `AP_PASSWORD` placeholder locally with a unique lab password; never commit the real password.
- [ ] Confirm the firmware builds with the documented ESP32 core and partition scheme.
- [ ] Redact nearby SSIDs, BLE observation IDs, and personal desktop details from screenshots.
- [ ] Do not commit CSV exports from real environments; `.gitignore` excludes `*.csv` by default.
- [ ] Add your preferred author name and GitHub profile to `README.md`.
- [ ] Choose and add a license if you want others to reuse the code.
- [ ] Create a public GitHub repository and upload this folder.
- [ ] Add a short release note describing the tested board and core version.
